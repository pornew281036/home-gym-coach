      ลิงก์ถาวร (GitHub Pages)

      ถ้าอัปขึ้น GitHub Pages แล้ว เปิดจากลิงก์ https://ชื่อคุณ.github.io/home-gym-coach/ — ไม่ต้องเปิด Mac · คู่มือในไฟล์ คู่มือ_GitHub_Pages.md

      ทำให้ข้อมูลต่อเนื่อง

      1. ใช้มือถือเครื่องเดียว + เพิ่มไปหน้าโฮม (Add to Home screen)
      2. เปิดจาก ลิงก์เดิมทุกครั้ง — ถ้า IP Mac เปลี่ยน ข้อมูลจะไม่โผล่ (คนละที่เก็บ)
      3. ส่งออก JSON ทุกสัปดาห์เก็บไว้ (สำรอง)
      4. ย้ายเครื่อง/IP ใหม่ → นำเข้า JSON กลับ

      รูป Fitdays เก็บในเครื่องแยก — ไฟล์ JSON มีตัวเลข/แผนยก แต่รูปเก่าอาจไม่ตามไปด้วย

      วิธีเปิดบนมือถือ

      1. บน Mac รันสคริปต์ start_server.sh
      2. มือถือกับ Mac อยู่ Wi‑Fi เดียวกัน
      3. เปิดลิงก์ที่สคริปต์แสดงบนมือถือ
      4. Chrome: เมนู → Add to Home screen
